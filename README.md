# Chanakya's File Organizer

A minimal desktop app that tidies up cluttered folders.

## Features

- Renames each file to its modified date and time (e.g. 2026-10-27_13-57-35.jpg)
- Sorts files into YEAR / MONTH / TYPE folders (e.g. 2026/OCTOBER/JPG)
- Supports JPG/JPEG, PNG, PDF, DOC/DOCX and XLS/XLSX
- Adds -1, -2 and so on to duplicate names, so nothing is overwritten

## Install

Download the latest `.deb` from [Releases](../../releases/latest), then run:

```bash
sudo apt install ./c-file-organizer_1.1.0_all.deb
```

Requires Debian 12+ or Ubuntu 22.04+. Dependencies are installed automatically.

## Uninstall

```bash
sudo apt remove c-file-organizer
```
